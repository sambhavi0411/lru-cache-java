# LRU Cache in Java

A production-style implementation of a Least Recently Used (LRU) Cache using:

- HashMap
- Doubly Linked List

## Features

- O(1) get()
- O(1) put()
- Generic implementation
- Clean architecture
- Unit tests
- Well documented

## Data Structures

- HashMap
- Doubly Linked List

## Time Complexity

| Operation | Complexity |
|-----------|------------|
| get | O(1) |
| put | O(1) |
| remove | O(1) |
